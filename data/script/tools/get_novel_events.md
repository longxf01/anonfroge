# 工具：get_novel_events

## 用途

按章节范围读取本项目已提取的小说章节事件，是创作时获取原著事实的主要来源。

## 参数

- `start_chapter`（整数，可选）：起始章节序号；
- `end_chapter`（整数，可选）：结束章节序号；
- 两者缺省或为 0 时，默认使用创作配置中的“原著范围”。

## 返回

- `totalCount`：命中事件总数；
- `truncated`：结果是否被截断（超过单次返回上限）；
- `events`：事件列表，每项含 `chapterIndex`（章节序号）、`chapterTitle`（章节标题）、`reel`（卷名）、`event`（结构化事件 JSON 文本）。

## 使用时机

生成故事骨架、改编策略或剧本草案前必须调用本工具读取原著章节事件；禁止凭记忆编造章节事件、人物关系或情节因果。
