# 工具：get_project_config

## 用途

读取当前项目的创作配置，这是后续故事骨架、改编策略与剧本生成的唯一约束来源。

## 参数

无参数。

## 返回

配置字典，包含以下字段：

- `totalEpisodes`：集数；
- `episodeDuration`：单集时长；
- `sourceRange`：原著范围（如“第1-50章”）；
- `platformSpec`：平台规格（横屏/竖屏等）；
- `style`：风格定位；
- `paywall`：付费策略。

## 使用时机

任何涉及集数、单集时长、章节范围、平台规格、风格或付费策略的创作与回答，必须先调用本工具读取配置；禁止使用记忆值、默认值或硬编码值。
