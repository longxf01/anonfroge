# 规则生存闯关 · 导演叙事手法技能包

## 简介

本技能包为 **规则生存闯关** 类型故事提供商用级导演叙事方法，覆盖从关卡规划、系统长线到分镜表执行的生产流程。它只处理故事讲述、规则信息、人物调度、节奏、声音、镜头和转场，适用于任何视觉风格，可与 `data/skills/art_list` 中的美术风格独立组合。

## 核心理念

| 维度 | 要求 |
|---|---|
| 类型核心 | 规则识别、试错验证、漏洞破局、群像协作、系统谜团 |
| 离场感受 | 高压释放后能够复盘规则与线索，并相信角色靠观察、勇气和协作赢得出口 |
| 规划重点 | 关卡目标、规则层级、违规代价、信息分工、长线回收、关系阶段和节奏释放 |
| 分镜重点 | 观众信息、角色信息、规则状态、空间证据、动作因果、时长、声音和连续性 |

## 技能文件说明

### 1. 叙事规划手法

`director_manual/director_planning_narrative.md` 用于确定关卡目标、规则层级、验证顺序、违规代价、角色分工、漏洞证据、长线谜团、双主角关系、声音和镜头策略。

### 2. 分镜表叙事手法

`director_manual/director_storyboard_table_narrative.md` 用于把规则状态和破局因果落到现有分镜字段，控制观众已知、角色已知、验证动作、违规结果、空间连续、证据回收和高潮节奏。

### 3. 概念图

`images/concept_image_prompt.md` 和 `images/director_concept.png` 用原创封闭公共空间、可见规则证据和群像分工表达本类型气质，不绑定具体作品或视觉风格。

## 使用方式

1. 读取 `director_planning_narrative.md`，先确定关卡边界、规则层级和局部目标。
2. 为每条规则建立“出现位置、验证动作、结果、漏洞和回收镜头”。
3. 用单元关卡解决局部危机，并推进一条系统级长线谜团。
4. 读取 `director_storyboard_table_narrative.md`，将规则和行动因果写入可执行分镜。
5. 叠加 `data/skills/art_list` 中任意视觉风格，生成具体画面或视频镜头。

## 商用边界

- 不引用具体导演、画师、演员、公司、品牌、平台、作品、角色或可识别 IP。
- 不复制外部项目的规则、关卡、谜题、人物关系或经典镜头。
- 规则挑战只描述虚构叙事中的观察、选择、协作和安全逃离，不提供现实危险行为教学。
- 不用随机伤害替代规则因果，不用露骨伤害细节制造刺激。
- 不把视觉材质、线条或固定配色写成导演叙事风格。
