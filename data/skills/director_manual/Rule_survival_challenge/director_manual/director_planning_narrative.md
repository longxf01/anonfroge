# 叙事手法 · 规则生存闯关 · 商用导演规划手册

## 一、商业定位

本手册将规则生存闯关的类型规律转化为可执行的关卡目标、规则层级、验证动作、人物分工、长线谜团、声音、构图和镜头策略。它不规定画面材质、线条或配色，只负责故事如何讲、规则何时出现、角色如何验证以及观众为什么相信最终解法。

| 维度 | 商用要求 |
|---|---|
| 类型核心 | 规则识别、试错验证、漏洞破局、群像协作、系统谜团 |
| 离场感受 | 高压释放后可以复盘规则和证据，相信出口来自观察、勇气与协作 |
| 输出对象 | 导演规划、关卡卡片、分场意图、分镜前置策略和视频镜头说明 |
| 适配范围 | 可与写实、漫画、动画、水墨、3D、像素和定格等任意视觉风格组合 |
| 禁止替代 | 不用随机伤害代替规则因果，不用旁白解释代替可见验证 |

## 二、主题立意与人物内核

| 原则 | 导演判断 | 落地方式 |
|---|---|---|
| 规则代表权力边界 | 规则不仅制造难题，还体现系统、组织或环境如何控制人物。 | 通过入口、许可、处罚、资源和观察权限呈现 |
| 破局来自主动认知 | 人物必须观察、质疑、验证和承担选择，不等待外部救援。 | 每次推理后安排可见动作验证 |
| 代价改变策略 | 违规结果必须让团队调整方案，而不是只增加伤亡数字。 | 改变路线、分工、资源、时间或信任 |
| 协作不是背景 | 群像成员拥有不同信息和能力，缺少任何关键环节都无法完成解法。 | 分配观察、推理、执行、保护和质疑职责 |
| 自由通过选择成立 | 结局不只是离开空间，还要回应人物是否拒绝成为规则的复制者。 | 让最终选择改变关系或系统长线 |

### 主题写法

- 主题必须落在可见选择，例如是否共享线索、是否为陌生人保留出口、是否利用漏洞伤害他人。
- 对立力量应代表控制、服从、效率、恐惧或自保逻辑，不只是一名脸谱化反派。
- 每个关卡至少让一名角色改变对规则、同伴或自身能力的认识。
- 长线结局必须回应首个关卡提出的自由、信任、身份或回归问题。

## 三、单元关卡八段结构

| 阶段 | 叙事功能 | 压力方向 | 导演控制点 |
|---|---|---|---|
| 异常进入 | 建立封闭环境、局部目标、人物位置和可能出口 | 陌生、警觉 | 先让观众读懂空间，再制造异常 |
| 规则公布 | 展示明确规则、隐含规则和疑似误导 | 注意力收紧 | 规则必须可见、可听或可由行动确认 |
| 首次验证 | 用低成本动作测试规则边界 | 好奇转紧张 | 呈现准备、动作、触发、结果和反应 |
| 代价显现 | 违规结果改变团队策略和资源 | 压迫、失衡 | 克制伤害细节，突出因果与选择 |
| 信息分工 | 群像交换线索、建立假设并分配任务 | 紧张中形成秩序 | 每人拥有明确的信息价值 |
| 漏洞发现 | 从规则冲突、物件状态、空间变化或声源中找出可利用边界 | 认知加速 | 解法证据必须此前出现 |
| 反向破局 | 人物主动利用规则，让控制机制反作用于自身 | 高压、主动 | 行动目标、路线和风险清楚 |
| 余波回收 | 完成局部目标，确认代价、关系变化和长线证据 | 释放、余震 | 不用长口播复盘，保留系统下一层问题 |

### 八段结构硬约束

```text
异常进入 → 规则公布 → 首次验证 → 代价显现
→ 信息分工 → 漏洞发现 → 反向破局 → 余波回收
```

- 可以压缩相邻阶段，但不得跳过规则验证、证据回收和行动破局。
- 每条关键规则至少有一次出现、一次验证和一次结果。
- 每个漏洞必须来自此前可见的规则冲突、道具状态、空间证据、声音证据或人物行动。
- 禁止临近结尾突然新增规则、外部救援、无依据牺牲或纯解释式解法。

## 四、长线系统谜团与单元回收

| 层级 | 功能 | 控制要求 |
|---|---|---|
| 当前动作 | 角色此刻必须完成的安全动作 | 镜头内目标清楚，结果立即可见 |
| 当前规则 | 本场或本关正在验证的规则 | 明确已知、未知和争议部分 |
| 单元谜题 | 当前关卡的出口与代价 | 本关闭合，不拖成无尽悬念 |
| 人物谜团 | 身份、记忆、关系或能力来源 | 通过动作、物件、声源和空间记忆递进 |
| 系统谜团 | 关卡为何存在、谁获益、控制边界在哪里 | 每关推进一小步，不一次解释完 |

### 长线规划原则

- 每个关卡解决一个局部目标，并推进一条系统级问题。
- 长线证据采用重复物件、构图、声源或规则措辞回环，每次出现改变含义。
- 人物记忆和身份信息必须有现实锚点，避免仅靠梦境或旁白。
- 关卡难度升级体现为信息不对称、资源收缩或选择代价增加，不只增加怪物和追逐。
- 同一种规则机制再次出现时，必须改变人物关系、团队分工或系统理解。

## 五、典型场景设计矩阵

| 场景类型 | 叙事用途 | 情绪方向 | 风险边界 |
|---|---|---|---|
| 封闭入口 | 建立进入方式、退出限制和人数关系 | 陌生、受控 | 入口和出口位置必须可复盘 |
| 规则载体 | 无字图形、广播、灯光、道具或空间变化传达要求 | 集中、怀疑 | 规则信息停留到观众能理解 |
| 低成本验证区 | 允许角色安全测试距离、顺序、声音或物件反应 | 谨慎、试探 | 不以随意伤害他人做实验 |
| 分工现场 | 群像同时观察不同方向并交换线索 | 混乱转协作 | 人物位置和任务不能混淆 |
| 错误安全区 | 看似安全的空间暴露隐藏代价 | 短暂放松转警觉 | 反证必须提前存在 |
| 漏洞证据点 | 规则冲突、磨损、反射、回声或计时差显现 | 恍然、加速 | 不用特效替代逻辑 |
| 反向执行区 | 角色按新方案同步行动 | 高压、主动 | 先交代路线与分工，再提高剪辑密度 |
| 余波出口 | 确认人数、代价、关系和长线证据 | 释放、余震 | 不把离场等同于所有问题解决 |

### 分场景要求

- 每场先写“规则状态改变了什么”，再写画面、行动和台词。
- 场景中的空间、物件、声音或人物动作至少一项承担证据功能。
- 纯气氛场景若不改变规则、信息、关系或行动方案，应删除或合并。
- 同一空间重复出现时，入口、出口、灯光、道具和人物站位必须保留连续性。

## 六、群像分工与双主角关系

### 群像功能

| 功能 | 行为表现 | 避免 |
|---|---|---|
| 观察者 | 记录重复、差异、时间、声音和空间变化 | 只负责惊讶 |
| 推理者 | 组织证据、提出假设并承认不确定性 | 无证据天才结论 |
| 执行者 | 将假设转成可控行动并确认结果 | 鲁莽送命工具人 |
| 保护者 | 管理撤离路线、资源和弱势成员安全 | 只有战斗能力 |
| 质疑者 | 指出遗漏、利益冲突和验证风险 | 为争吵而反对 |

### 双主角关系阶段

```text
能力对峙 → 被迫合作 → 行动默契 → 记忆回响 → 共同选择
```

- 能力对峙：通过不同解题方法、站位和风险判断建立差异。
- 被迫合作：外部规则要求信息互补，不靠偶然肢体接触制造关系。
- 行动默契：一人改变路线时，另一人无需解释即可补位；镜头完整呈现配合。
- 记忆回响：旧动作、声源、物件或空间触发熟悉感，不一次解释全部过去。
- 共同选择：两人面对系统利益、个人出口和群体安全时作出可见且有代价的选择。

### 节奏释放

- 冷幽默来自人物观察、规则荒谬和性格反差，不打断真实危险。
- 群像善意通过让位、交接、回头确认和资源分享表达。
- 感情线通过站位、视线、动作接力和承担风险推进，不套用日常甜宠桥段。
- 高压段落后保留呼吸、清点和关系反应，避免立刻进入下一次刺激。

## 七、声音与音乐方向

| 声音策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 规则声源 | 广播、电流、铃、机械切换或空间回声传递边界 | 声源位置和出现条件可追踪 |
| 验证反馈 | 灯灭、门锁、金属震动、风向或脚步回声确认结果 | 与动作触发准确同步 |
| 倒计时压力 | 重复但逐步变化的环境节奏压缩决策时间 | 不用全程低频轰鸣 |
| 信息分离 | 不同空间的声源让群像获得不完整信息 | 观众知道哪些角色听见了什么 |
| 漏洞回声 | 前文声源以时间差、方向差或缺失状态重新出现 | 回收此前已建立的声音 |
| 破局静默 | 关键选择前撤掉音乐，让呼吸和动作承担重量 | 静默前后必须有信息变化 |
| 释放音景 | 出口开启后恢复真实环境声，确认空间状态变化 | 不立即用胜利音乐覆盖代价 |

### 声音规划原则

- 所有声音写清声源、方向、进入时机、持续时间和退出条件。
- 同一声音锚点每次出现都改变规则理解或人物状态。
- 角色听见与观众听见的范围可以不同，但必须明确设计信息差。
- 音乐只服务预兆、压力、反差、选择和余波，不替代规则反馈。

## 八、构图与景别叙事

| 景别或构图 | 叙事用途 | 执行约束 |
|---|---|---|
| 定场全景 | 保存入口、出口、规则载体、人物位置和安全区 | 首次进入必须给足阅读时间 |
| 群像全景 | 展示分工、距离、路线和谁被隔离 | 保持左右关系和摄影轴线 |
| 双人中景 | 表现策略交换、能力对峙和行动默契 | 不用浅景深抹掉关键环境 |
| 规则特写 | 展示道具状态、灯光变化、计时差和结构证据 | 停留到观众能理解 |
| 反应近景 | 确认角色理解、怀疑或改变计划 | 反应必须承接具体信息 |
| 受限视角 | 让观众只获得某角色可见范围 | 后续必须交代被遮挡空间 |
| 回收构图 | 重复前文角度并改变道具、人物或光线意义 | 构图相似度足以触发记忆 |

### 构图控制

- 先建立空间再限制视野，不能用混乱构图掩盖规则漏洞。
- 前景、中景、背景至少两层承担规则、人物或出口信息。
- 线条、门框、灯带、地砖和道具可以标记安全边界，但不能只做装饰。
- 破局前用全景确认路线与分工，高潮中才允许更密集的中近景切换。

## 九、镜头运动与段落节奏

| 运镜策略 | 叙事用途 | 执行约束 |
|---|---|---|
| 空间扫描 | 从入口经过规则载体到可能出口，建立可复盘地图 | 起点、路径和终点明确 |
| 受限跟拍 | 跟随验证者接近边界，让观众共享有限信息 | 保持退路和朝向可见 |
| 横移并置 | 展示多个角色同时执行不同任务 | 不跳轴、不混淆职责 |
| 突然停住 | 规则反馈或逻辑冲突出现时冻结行动 | 停止点落在证据或反应 |
| 回拉揭示 | 从局部证据拉到整体空间，说明漏洞如何成立 | 不新增此前不可见信息 |
| 稳定长看 | 最终选择、承担代价或关系确认 | 减少花哨运动 |

### 节奏控制

- 规则首次展示要慢到可理解，重复规则可缩短但要显示状态变化。
- 一次验证动作完整呈现“准备 → 动作 → 触发 → 结果 → 反应”。
- 倒计时段提高的是信息密度和并行动作，不是无理由缩短所有镜头。
- 高潮快切前必须用全景确认路线、人物位置和同步目标。
- 破局后保留清点、呼吸和关系反应，让代价被观众接住。

## 十、常见失败模式与修正

| 编号 | 失败模式 | 修正方向 |
|---|---|---|
| 1 | 规则只在结尾出现，角色无法公平推理。 | 提前放入可见规则、物件状态、空间或声音证据。 |
| 2 | 角色靠天才直觉给答案，没有验证过程。 | 增加假设、低成本试错、反馈和方案修正。 |
| 3 | 随机伤亡代替违规因果。 | 让代价对应具体触发条件并改变团队策略。 |
| 4 | 群像只负责惊叫和被救。 | 分配观察、推理、执行、保护和质疑功能。 |
| 5 | 关卡只靠追逐和怪物升级。 | 提高信息差、资源限制、选择代价和规则冲突。 |
| 6 | 最终解法依赖新规则或外部救援。 | 从前文规则冲突、道具、空间、声源或行动回收解法。 |
| 7 | 关系线靠糖水桥段打断危机。 | 用站位、补位、动作接力和共同选择推进关系。 |
| 8 | 视觉阴暗但规则、空间和路线不可读。 | 增加定场全景、规则特写、路线确认和反馈镜头。 |
| 9 | 全程高压导致疲劳。 | 在关卡节点加入冷幽默、群像善意、清点和呼吸。 |
| 10 | 破局后长对白解释全部设定。 | 用回收构图、声源变化、道具状态和简短确认完成余波。 |

## 十一、商用验收清单

| 验收项 | 通过标准 |
|---|---|
| 关卡目标 | 人物为何进入、要完成什么、出口条件和失败代价清楚。 |
| 规则层级 | 明确规则、隐含规则、疑似误导和当前验证状态可区分。 |
| 公平解法 | 最终破局只使用此前可见的规则、物件、空间、声音和行动证据。 |
| 行动因果 | 关键验证完整呈现准备、动作、触发、结果和反应。 |
| 群像功能 | 观察、推理、执行、保护和质疑均由具体角色承担。 |
| 长线推进 | 单元关卡闭合，同时推进至少一项人物或系统谜团。 |
| 关系变化 | 双主角或核心关系通过行动和选择发生可见变化。 |
| 空间连续 | 入口、出口、路线、摄影轴线、人物位置和规则载体可复盘。 |
| 声音设计 | 规则声源、反馈、倒计时、静默和释放均有明确功能。 |
| 安全边界 | 不展示露骨伤害，不提供现实危险行为的可操作教学。 |
| 商用边界 | 不引用具体作品、角色、导演、品牌、平台或可识别 IP。 |

## 十二、与视觉风格的组合规则

- 本手册只定义规则、信息、人物行动、声音、镜头和节奏，不绑定固定美术样式。
- 美术风格负责线条、材质、色彩、光影和媒介；本手册负责规则如何出现、验证和被利用。
- 当视觉氛围与信息可读性冲突时，优先保证规则、路线、人物位置和动作结果清楚。
- 生成导演规划、分镜表或视频镜头前，先读取本手册，再叠加 `data/skills/art_list` 中的艺术风格。
