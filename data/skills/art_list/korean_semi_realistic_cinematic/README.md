# 韩系电影级半写实插画风（Korean semi-realistic cinematic illustration）艺术风格手册

本文件是 `korean_semi_realistic_cinematic` 风格目录的唯一主文档，集中管理风格定位、资产提示词、镜头提示词、连续性、质量验收和风险规避规则。该风格以精修数字绘画为媒介，保持韩系人物审美与电影镜头感，但不生成平涂韩漫、真人摄影或塑料 3D 画面。

## 1. 商用定位

| 维度 | 内容 |
|---|---|
| 中文名称 | 韩系电影级半写实插画风 |
| 英文通用词 | Korean semi-realistic cinematic illustration |
| 风格分类 | 动画/漫画 |
| 适用内容 | 都市情感、悬疑、规则闯关、轻幻想、现代剧情 |
| 情绪基调 | 克制、精致、冷静、电影化 |
| 媒介基础 | 精修数字绘画与电影构图 |
| 轮廓系统 | 弱线稿或无线稿，以明暗塑形和焦点相关的软硬边缘区分层级 |
| 人物系统 | 近写实骨相与人体比例，五官适度理想化，不改变年龄和身份特征 |
| 材质系统 | 柔和哑光皮肤、成组发束、自然布料、克制的玻璃与金属反射 |
| 光影系统 | 有来源的主光、柔和补光、克制轮廓光、浅景深、空气透视 |
| 色彩系统 | 中性肤色、冷灰暗部、暖色实景灯，低至中饱和、受控冷暖对比 |
| 镜头系统 | 35mm 空间叙事、50mm 双人互动、85mm 人像近景 |

### 适合使用

- 需要人物比传统韩漫更接近真实骨相，又必须保留数字插画审美。
- 需要统一生成角色设定、场景设定、道具设定和连续镜头。
- 需要利用电影布光、景深和焦点边缘控制人物情绪。
- 需要在都市、悬疑、轻幻想或规则闯关场景之间切换，而不改变主媒介。

### 不适合使用

- 完全写实的新闻、纪录片、商业摄影或真人写真。
- 粗轮廓、平涂、网点、速度线明显的传统漫画画面。
- 依赖真实演员面孔、知名角色、作品构图或品牌视觉的模仿任务。
- 纯 3D 产品渲染、游戏引擎截图或强调物理级皮肤毛孔的超写实图像。

## 2. 风格视觉 DNA

| 模块 | 商用控制要求 |
|---|---|
| 骨相 | 保持近写实颅面结构、颌面转折和五官体积；理想化只用于比例精修，不抹平年龄、性格和身份差异。 |
| 眼睛 | 尺寸接近真实成人比例，用眼睑厚度、虹膜明暗和视线表达情绪；禁止动漫式大眼和玻璃珠眼。 |
| 皮肤 | 以光影塑造柔和哑光皮肤，保留少量自然色差和结构转折；禁止陶瓷皮、蜡像皮和重度磨皮。 |
| 头发 | 先固定发型外轮廓和主要发束，再增加少量碎发与高光；禁止逐根噪点发丝和头盔式硬块。 |
| 轮廓 | 焦点区域使用清晰但无明显描边的硬边，非焦点区域使用软边和空气透视；禁止统一粗线稿。 |
| 材质 | 布料、皮革、金属、玻璃、木石必须通过粗糙度、折痕、反射和边缘磨损区分，不使用统一塑料高光。 |
| 光影 | 每个镜头写清主光来源、方向、色温和作用；补光与轮廓光不得违背场景物理光源。 |
| 色彩 | 肤色保持中性，暗部偏冷灰，实景灯可提供暖金点缀；单镜头核心色不超过 5 个。 |
| 景深 | 只在叙事需要时使用浅景深，焦点必须落在人物眼睛、关键动作或道具证据上。 |
| 连续性 | 批量生成时固定角色骨相、发型、体型、服装剪裁、主色、场景轴线、关键道具和主光方向。 |

### 核心风格锚点

```text
Korean semi-realistic cinematic illustration, polished digital painting,
near-realistic anatomy and facial structure, subtly idealized refined features,
soft matte skin rendered through light and shadow, clean focus-dependent edges,
detailed grouped hair strands, cinematic motivated lighting,
shallow depth of field, atmospheric perspective, restrained color grading
```

### 媒介边界

- 主媒介必须写为 `cinematic illustration` 与 `polished digital painting`。
- 焦段、景深、机位和布光属于电影镜头语言，不代表摄影媒介。
- 不使用 `RAW photo`、`DSLR photo`、`documentary photography` 作为主风格词。
- 不使用 `CGI`、`3D render`、`game engine render` 作为主风格词。

```text

```

### 通用负向约束

```text
no flat webtoon coloring, no thick comic outlines, no cel shading,
no photorealistic camera look, no waxy skin, no plastic doll face,
no 3D render appearance, no exaggerated anime proportions,
no identical generic faces, no excessive beauty filter,
no broken anatomy, no malformed hands, no extra fingers,
no inconsistent identity, no costume drift, no conflicting light directions,
no text, no subtitles, no logo, no watermark
```

### 提示词权重原则

1. 先写主体、动作和身份，再写风格；避免模型只生成“漂亮人物”而丢失叙事。
2. 风格锚点保持稳定，不在同一提示词中叠加平涂韩漫、真人摄影或 3D 渲染。
3. 材质必须落到具体表面，不只写“高级”“精致”“电影感”。
4. 每个镜头只指定一个焦点，背景细节锐度必须低于主体。
5. 负向约束置于提示词末尾，并补充当前资产最容易出现的具体错误。

## 4. 角色资产规范

### 角色身份锁

| 项目 | 必填内容 |
|---|---|
| 骨相 | 脸型、颌线、颧骨、眉骨、鼻梁与鼻尖结构 |
| 五官 | 眉眼距离、眼睑形态、虹膜色、唇形和静态神态 |
| 发型 | 长度、分区、外轮廓、主要发束、发色和碎发位置 |
| 身体 | 年龄段、身高范围、肩胯比例、体型和惯常姿态 |
| 服装 | 领型、肩线、腰线、下装、鞋履、材质、主色和状态 |
| 识别点 | 一个原创且无文字无标志的几何配饰、伤痕、色块或结构细节 |


### 角色衍生

```text
保持同一原创角色身份锁，固定脸型、眉眼距离、鼻唇结构、发型外轮廓、体型、服装剪裁、主色与原创识别点，仅改变{情绪/动作/服装状态/年龄阶段}，镜头{全身/中景/近景/特写}，{35mm/50mm/85mm}等效焦段，主光{来源与方向}，韩系电影级半写实插画风，精修数字绘画，近写实骨相，柔和哑光皮肤，成组发束，焦点相关的软硬边缘，保持身份连续一致。
```

### 角色验收

- 多张图缩略查看仍能确认是同一角色，而不是同一种“网红脸”。
- 正侧背视图的颅面结构、肩胯比例、服装缝线和配饰位置一致。
- 平静、警觉、愤怒、惊讶、悲伤、克制微笑六种表情不改变骨相。
- 手部、脚部、坐姿、转身、奔跑和持物动作符合近写实解剖。
- 近景皮肤存在体积和自然色差，但不出现摄影级毛孔堆砌。

## 5. 场景资产规范

场景必须同时服务空间连续性、人物走位和电影光影。每个主场景固定建筑骨架、入口、轴线、角色行动区、关键道具位置和主光来源。


### 场景四状态

```text
保持同一原创场景的建筑骨架、入口、楼梯、行动区、关键道具位置、摄影轴线和主光逻辑完全一致，以四格设定板展示{正常状态}、{天气或昼夜状态}、{剧情异常状态}、{事件后状态}，每格只改变天气、光线、表面状态和剧情痕迹，不改变空间结构，韩系电影级半写实插画风，精修数字绘画，真实透视，电影级有来源光线，清晰远中近层次。
```

### 场景验收

- 四状态图可以叠合主要建筑线，不出现门窗、楼梯和出口漂移。
- 行动区无遮挡，远中近至少两层承担叙事功能。
- 主光方向、阴影落点和反射逻辑可追踪。
- 35mm 空间镜头不产生夸张鱼眼或人物边缘拉伸。
- 场景有绘画边缘和受控细节，不偏建筑摄影或游戏引擎截图。

## 6. 道具资产规范

道具必须具备尺度、结构、表面、交互点、叙事功能和状态连续性。

### 道具设定板

```text
原创漫剧道具设定板，{道具名称}，叙事功能{功能}，使用者{身份}，尺度{尺寸与人体参照}，结构{组成与连接方式}，交互点{握持/开启/触发/观察位置}，材质{表面/粗糙度/反射/边缘磨损}，主色{颜色}，辅助色{颜色}，状态{初始/使用中/异常/损坏/修复}，韩系电影级半写实插画风，polished digital painting，clean focus-dependent edges，cinematic motivated studio lighting，正面、侧面、背面、俯视、关键结构和材质细节，同一物体比例与结构一致，干净背景，无文字无标志。
```

### 道具状态连续

| 状态 | 画面要求 |
|---|---|
| 初始 | 结构完整、交互点清楚、功能可读。 |
| 使用中 | 增加指纹雾、折痕、灰尘或边缘轻微磨损，位置与使用方式一致。 |
| 异常 | 异常光、热、裂纹或位移必须来自已有结构，不凭空增加装饰。 |
| 损坏 | 裂口、凹陷、烧灼和变形具有受力方向和因果。 |
| 修复 | 新旧材料交界、补丁、加固或替换件清楚，保留历史状态。 |

### 道具验收

- 多视图比例、孔位、接缝和配件数量一致。
- 道具在角色手中、桌面和特写镜头中的尺度一致。
- 金属、玻璃、皮革和纸张拥有不同粗糙度，不使用统一塑料反光。
- 异常效果不遮挡原有结构和叙事证据。

## 7. 分镜与视频规范

### 焦段与景别

| 焦段 | 推荐用途 | 控制要求 |
|---|---|---|
| 35mm | 定场、群像、走位、人物与环境关系 | 保持空间透视自然，主体不要贴画面边缘 |
| 50mm | 双人互动、中景行动、过肩对话 | 兼顾表演和空间，不用过浅景深切断关系 |
| 85mm | 人物近景、微表情、关键道具 | 焦点落在眼睛或证据，背景散景保持可辨环境色 |

### 单镜头公式

```text
韩系电影级半写实插画风，{景别}，{机位高度与角度}，{35mm/50mm/85mm}等效焦段，镜头从{运动起点}以{速度}移动至{运动终点}，时长{秒数}秒，{角色}在{场景}中完成{一个连续动作链}，视线{方向与目标}，情绪{情绪节拍}，关键道具位于{位置/状态}，主光来自{方向/色温/场景光源}，柔和补光，克制轮廓光，polished digital painting，near-realistic anatomy and facial structure，soft matte skin rendered through light and shadow，clean focus-dependent edges，shallow depth of field，atmospheric perspective，保持角色骨相、发型、服装、道具、场景轴线、左右关系和光源连续一致。
```

### 三镜头段落

| 镜头 | 景别与焦段 | 叙事职责 | 连续性 |
|---|---|---|---|
| S01 | 全景或远景，35mm | 建立空间、人物位置、出口、主光和行动目标 | 固定摄影轴线与左右关系 |
| S02 | 中景或过肩，50mm | 完成动作推进、交接、试探或关系变化 | 承接上一镜动作终态与道具位置 |
| S03 | 近景或特写，85mm | 落在微表情、选择或关键证据 | 焦点明确，不突然改变脸型和光向 |

### 视频连续性

- 每镜只承载一个核心动作拍，写清起点、过程和终点。
- 上一镜的手势、视线、身体朝向和道具状态必须成为下一镜开头。
- 对话和对峙保持 180 度线，不无理由交换人物左右位置。
- 运镜必须有信息目的；固定镜头能完成叙事时不增加无效运动。
- 浅景深只用于强调，规则、证据和人物关系镜头必须保证必要信息可读。
- 视频提示词末尾追加通用负向约束，并增加 `no face morphing, no costume flicker, no background warping, no camera-axis jump`。

## 10. 使用边界

- 只使用通用媒介、地域审美、材质、光影、色彩、构图和镜头语言。
- 不使用具体人名、演员名、画师名、公司名、品牌名、平台名、作品名、角色名或可识别 IP 标志。
- 不复制参考截图的字幕、界面元素、人物身份、服装组合或完整构图。
- 最多叠加 3 个风格词：主风格 1 个、媒介质感 1 个、光影或情绪 1 个。
- 批量生产前先通过角色设定板、场景四状态和代表镜头确认风格，再生成连续镜头。
- 若结果偏平涂韩漫，降低线稿权重并强化明暗塑形与焦点边缘。
- 若结果偏真人摄影，移除摄影媒介词并强化 cinematic illustration 与 polished digital painting。
- 若结果偏塑料 3D，移除渲染词并强化哑光皮肤、绘画边缘、材质粗糙度和克制反射。
